# AI Product Recommendation Engine

The recommendation feature is owned by Student 5 (Aiden Phan). It helps KICKLAB customers find men's sneakers through a chatbot and a recommendation carousel.

Pages:
- http://localhost:3005/ is the shopping assistant and recommendation carousel
- http://localhost:3005/mcp runs shared MCP tools for recommendations
- http://localhost:3005/rag asks grounded questions about this feature

The frontend runs on port 3005, the API backend on port 5005, and the recommendations database on port 6005.

Recommendations combine three scores: chat match 55 percent, content-based filtering 30 percent, and collaborative filtering 15 percent. When a customer says a budget such as "shoes under 120", products above that price are excluded.

Each recommendation card has a "The reason why" panel. Customers can mark a pick helpful or not, and that feedback is stored in recommendation_feedback.

The chatbot reply is generated by a local Ollama model. The ranked product list is calculated in the backend, not chosen by the language model.
