# KICKLAB Orders: viewing an order

Log in through the shared store and select My Orders. View Details shows an
order's items, quantities, total and status. Check with MCP performs a read-only
status lookup using the store login. It permits the owning customer or
authenticated staff. If its authentication expires, select Check with MCP again
to obtain fresh authentication. The Orders guide answers general documentation
questions; use MCP for a particular order's current status.

Source: shared/backend/app.py; student-4/backend/orders_auth.py; student-4/frontend/templates/index.html.
