# KICKLAB Orders guide scope

The Orders guide searches public documentation about order statuses,
cancellation behavior and viewing orders. It does not search customer records,
addresses or individual order data. It cannot establish a delivery date,
shipment tracking number, refund entitlement or payment outcome. These features
are not implemented in the Orders service. Answers must use the retrieved
documentation. When documentation cannot support an answer, the guide reports
insufficient context. Service failures are reported separately.

Source: student-4/database/app.py; student-4/backend/orders_rag.py.
